# Brent 周一方向预测只读设计

**状态：** 已于 2026-08-23 获用户确认  
**目标：** “Brent 周一方向预测日报”只消费周五已经落盘的 Brent、金十新闻和预测计算快照；周末运行不得触发任何网络抓取、历史回补、实时 freshness 校验或相同输入的整套重跑。

## 约束

- `forecast-report` 是硬只读命令，不提供“允许回补”的默认分支。
- 分析结束日必须是周五，目标日必须是紧随其后的周一。
- 预测输入来自确定路径的本地快照；快照缺失、损坏、日期不匹配或含未来数据时立即失败。
- 快照必须同时保存 Model A 量化结果、Model B/C 新闻结果和最终组合结果；周末不得重新抓 Yahoo、金十、ISW 或特朗普专栏，也不得重新拟合模型或重算新闻方向。
- 周末休市不是数据不新鲜。预测报告不运行滚动日报的实时边界 freshness 判定。
- 相同快照重复执行时直接返回已经生成的正式 Markdown/HTML 和结果清单，不再次生成整套报告。

## 数据流

1. 周五采集任务继续负责把 Brent、金十新闻及相关计算结果保存到本地。
2. `forecast-report` 解析日期并验证“周五 → 下周一”关系。
3. 命令读取 `<output_stem>_forecast_audit.json` 作为不可变的周五计算快照，校验日期、未来数据标志和必需字段，并计算 SHA-256。
4. 若 `<output_stem>_forecast_result.json` 的快照指纹一致且正式 Markdown/HTML 均存在，立即返回，标记 `reused=true`。
5. 否则仅使用快照中的 `quant`、`news`、`final` 构造预测卡；报告正文可以只读查询已经保存的数据库，但禁用刷新写入、外部补充抓取及实时 freshness 判定。
6. 成功后写入结果清单，记录快照指纹和产物路径，供后续执行复用。

## 报告审计语义

滚动日报的 freshness 适用于活跃抓取任务，不适用于冻结的周五快照。预测报告使用 `frozen_snapshot` 模式：

- 不检查价格是否延伸到周六 08:00，也不因周末没有新 K 线生成覆盖缺口；
- 对外显示“周五快照/不适用”，并以快照日期、输入完整性与无未来数据校验作为正式报告门槛；
- 仍可只读统计本地行数、时间戳质量和事件内容，但这些统计不会触发抓取、回补或重跑。

## 失败行为

- 快照不存在：报“缺少周五预测快照”，不尝试联网。
- 快照日期不符、缺少计算结果或 `future_data_used=true`：报快照校验错误，不尝试联网。
- 已有结果清单与快照指纹不一致：只重新渲染本地结果，不重新抓取或训练。

## 验收

- 测试把 Yahoo、金十回补、ISW、特朗普、量化拟合、新闻重算和实时 freshness 函数全部设置为“一旦调用即失败”，周末报告仍能从快照生成。
- 第二次使用相同快照时，报告构建函数也设置为“一旦调用即失败”，命令仍返回既有产物。
- 周五 2026-08-21 快照预测 2026-08-24 时生成 `FORMAL` 产物，不因最后一根 5 分钟 K 线早于周六 08:00而降级。
- 快照缺失测试证明命令快速失败且无任何兜底抓取。
