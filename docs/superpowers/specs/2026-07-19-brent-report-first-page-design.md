# Brent 日报 HTML 第一页精简设计

## 目标

在不修改新闻抓取、筛选、Brent 异动识别、阈值、供给端硬门槛、数据库、Audit 和文件命名的前提下，把正式日报 HTML 改为以 K 线交互为主的单页摘要。正式 Markdown 继续保留现有完整内容，Audit 的生成逻辑与内容保持不变。

## 实现边界

- 只修改正式日报 HTML 渲染和现有 SVG 的交互表现。
- 交互详情仅复用正式 Markdown 中已经入选的事件组和新闻，不重新筛选或补充新闻。
- 无有效 HTTP(S) 原文链接的新闻不进入蓝色详情框；正式筛选逻辑和 Audit 排除记录不变。
- 不新增数据库字段、输出文件或外部前端依赖。

## 页面结构

正式 HTML 按以下顺序渲染：

1. 标题、统计窗口、数据来源；
2. Brent 四项关键指标卡；
3. 蓝色动态新闻详情框；
4. Brent 24 小时 K 线图；
5. “今日市场主线”简短卡片，最多三条；
6. “接下来关注什么”简短卡片，最多三条；
7. 查看完整 Audit 链接。

正式 HTML 不再渲染逐段复盘、解释不足长文、完整风险列表、核心驱动窗口重复汇总和外部网站长篇翻译。上述信息继续存在于正式 Markdown 和 Audit 中。

## 交互设计

- 蓝框默认提示用户点击下方蓝色新闻时间点。
- 点击蓝色新闻点后，蓝框显示事件时间段、累计涨跌幅、最大 30 分钟涨跌幅、5/15/30/60 分钟反应、该事件组全部正式入选新闻、一句话市场解读、归因和置信度。
- 每条新闻的标题和“查看金十原文 ↗”分别链接到同一个、独立的有效金十 URL，并在新标签页打开。
- 同一事件组全部新闻都保留；超过两条时默认展示前两条，并提供本地“展开全部/收起”按钮。
- 浅灰未解释区间增加鼠标和键盘点击能力。点击后，蓝框显示时间段、涨跌幅、“附近未找到满足硬门槛的新闻”、归因暂无法确认、置信度低。
- 点击仅更新蓝框，不调用滚动 API，不使用弹窗；当前蓝点或浅灰区间保留高亮。

## 数据映射

正式 HTML 渲染器解析现有正式 Markdown 的结构化段落，形成解释事件和未解释事件的只读展示数据。每个事件生成稳定事件键：优先复用事件 ID；无事件 ID 时使用规范化的北京时间起止时间。蓝色点以稳定事件键为主、已入选新闻 URL 为校验映射到解释事件；浅灰区间以规范化起止时间映射到未解释事件。页面输出顺序只作为无法取得稳定键时的防御性回退。映射失败时保留默认提示，不猜测归因。

## 响应式与可访问性

- SVG 继续允许横向滚动，避免移动端压缩后不可读。
- 蓝点和浅灰区间支持 Enter/Space 键触发，并提供焦点与当前选中样式。
- 蓝框、摘要卡和链接在窄屏下改为单列，触控目标不小于现有新闻标签。

## 验证

- 先新增失败测试，覆盖页面顺序、长内容不渲染、独立新闻链接、浅灰区间交互、无滚动/无弹窗、展开全部和移动端样式。
- 实现后运行全部现有单元测试。
- 使用 `Jin10_Brent_Rolling_Reaction_20260715_0800.html` 重新生成样本，只重建正式 HTML，并验证 Audit 文件哈希不变。
- 解析最终 HTML，确认每个展示新闻都有有效且独立的 HTTP(S) 金十链接。
