# Brent 日报：完整 ISW Key Takeaways、特朗普言论与顶部重点设计

日期：2026-08-05  
目标窗口：2026-08-04 08:00（含）至 2026-08-05 08:00（不含），Asia/Shanghai

## 1. 背景与目标

现有 Brent 日报按北京时间 08:00 滚动窗口生成，使用金十原始快讯与 Yahoo Finance `BZ=F` 5 分钟 K 线，先识别价格异动，再寻找满足直接能源传导硬门槛的新闻解释。ISW Iran Update 仅用于后续风险监测，不参与 Brent 异动归因。

本次在不改变上述核心口径的前提下完成三项扩展：

1. ISW 只抓取官网文章的 `Key Takeaways` 区段，但该区段内的全部条目必须按原顺序保留并逐条翻译，不得再按 2 条、6 条或 7 条截断。
2. 新增“特朗普相关言论”板块，仅使用金十数据“特朗普”专栏，完整收录窗口内特朗普本人涉及伊朗、霍尔木兹、战争、原油和制裁等主题的独立表态。
3. 在日报最上方新增 2–5 条“今日重点”，完成全报后从已验证内容中提炼，让读者先看到当日核心结论。

首个交付窗口为 2026-08-04 08:00 至 2026-08-05 08:00。本地数据库目前只更新到 2026-07-30，因此制作前必须先回补金十与 Brent 数据；不得用已有 HTML、Markdown 或搜索摘要反向写入事实库。

## 2. 不变范围

- Brent 异动仍按 `SPEC.md` 的 0.50% 强窗口和 0.25% 补充窗口规则扫描。
- 正式归因仍只来自金十原始快讯池，并通过直接能源供应、运输、制裁、库存、产量或关键航道传导硬门槛。
- HTML 蓝色面板的完整展示集合与 Markdown 严格归因集合继续分离。
- 无法解释的价格异动继续明确留白，不因特朗普或 ISW 内容而补写因果。
- ISW 与特朗普专栏均为独立补充板块，不反向修改 `selected_news`、核心驱动、Brent 反应标签或数据库中的正式归因字段。
- `FORMAL`、`PARTIAL`、`FAILED` 状态及价格完整性披露继续遵循 `SPEC.md`。

## 3. 日报阅读顺序

正式 Markdown 与 HTML 使用相同的主阅读顺序：

1. 报告标题。
2. `今日重点（Executive Summary）`：2–5 条。
3. 统计窗口、数据来源及必要的降级警告。
4. 标的信息与数据覆盖范围。
5. Brent 关键指标、30 分钟 K 线和蓝色新闻面板。
6. 本窗口 Brent 价格异动复盘。
7. 价格异动但新闻解释不足。
8. 未充分定价的重大风险。
9. 市场主要驱动与下一时段判断。
10. 特朗普相关言论。
11. ISW Iran Update — Key Takeaways。
12. 今日关注什么。
13. Audit 入口。

`今日重点` 是唯一的顶部摘要，不再在标题附近增加第二套重复摘要。

## 4. 今日重点生成规则

摘要必须在其余报告内容形成后生成，只使用本次报告已验证的数据与板块内容。按以下顺序选取 2–5 条，去除同义重复：

1. Brent 全窗口涨跌幅、日内高低点和最大异动方向；若价格不完整，明确写出状态，不输出伪精确结论。
2. 已通过正式归因硬门槛的最重要核心驱动；无合格新闻时改写为“主要异动缺少直接新闻解释”。
3. 对供应、航运、霍尔木兹、港口、制裁或产量有直接意义的独立重大事件。
4. 窗口内最具能源或战争意义的特朗普独立表态。
5. ISW Key Takeaways 中最值得继续监测的一项风险。

摘要条目必须能在正文对应板块找到证据；不得从外部搜索结果直接生成摘要。特朗普与 ISW 条目需标明其为“表态”或“研判”，避免写成已验证的市场因果。

## 5. ISW Key Takeaways 抓取与翻译

### 5.1 来源与截止时间

- 首选 ISW 官网最新一篇在报告截止时间前发布的 Iran Update。
- 官网失败时，可继续使用 ISW 官方 Bluesky 线程定位对应官网文章，但最终只采集官网文章的 `Key Takeaways`。
- 文章发布时间晚于 2026-08-05 08:00 北京时间时，不得用于本窗口。

### 5.2 区段边界

- 起点是正文中精确匹配的 `Key Takeaways` 标题。
- 终点是紧随其后的第一个同级正文国家/地区标题或文章正文主章节。
- 只排除网页导航、页脚、下载按钮、作者与站点通用说明等非正文元素。
- 不抓取 Key Takeaways 后的 Iran、Iraq、Lebanon、Syria、Yemen 等正文详述。

### 5.3 完整性与翻译

- 保存该区段内全部条目，保持原顺序、条目边界和引用编号。
- 每条英文原文必须有且只有一条对应中文翻译；不得截断句子、删除后半段或只取前若干条。
- 翻译可以清理多余空白，但不得改写事实、合并两个独立条目或删掉不直接涉及能源的 Key Takeaway。
- 缓存同时保存英文原文数组、中文翻译数组、来源标题、原文链接、发布时间、抓取方式和条目数量。
- 报告用 `Key Takeaways` 标题逐条展示全部中文翻译；保留原文链接和发布时间。
- HTML 不再限制最多 7 条。若条目较多，可使用可展开容器改善阅读，但所有条目必须存在于交付文件中并可访问。

### 5.4 完整性校验

- `source_key_takeaways_count == translated_key_takeaways_count == rendered_key_takeaways_count`。
- 三个数量任一不相等时，ISW 板块标记失败并披露原因，不得把部分翻译标为成功。
- ISW 失败不改变金十 + Brent 主报告状态，但 `今日重点` 不得引用失败或部分内容。

## 6. 特朗普相关言论板块

### 6.1 唯一来源

- 使用金十数据“特朗普”专栏：`https://xnews.jin10.com/topic/418` 及其公开加载接口。
- 不使用其他媒体、特朗普社交媒体原帖、搜索引擎摘要或普通金十全站结果补齐此板块。
- 每条记录保存金十标题、正文/摘要、发布时间、原文链接和专栏来源标识。

### 6.2 时间与主题过滤

- 只保留 2026-08-04 08:00（含）至 2026-08-05 08:00（不含）的记录。
- 必须是特朗普本人直接引语、转述表态、命令、威胁、谈判立场或政策宣布。
- 主题至少命中一类：伊朗、美伊谈判、霍尔木兹、地区战争或军事行动、原油/石油/油价/汽油、能源供应或油企、制裁/豁免/二级关税。
- 仅讨论特朗普但没有其当日相关表态的评论、历史回顾、人物分析和无关政治内容排除。

### 6.3 完整性与去重

- 保留窗口内每一个独立表态，不设条数上限。
- 同一讲话被多个金十条目重复转述时，可合并为一个代表表态，但必须在 Audit 中保存全部来源条目及代表映射。
- 同一场讲话中对“伊朗谈判”“霍尔木兹开放”“原油企业/零售油价”“制裁”等不同主题的独立立场不得互相吞并。
- 正文按北京时间升序展示：时间、表态摘要、主题标签、金十原文链接。若同一表态有多条金十来源，列出全部来源链接。
- 没有合格表态时明确写“本窗口金十特朗普专栏未发现符合主题条件的特朗普本人表态”，不得用普通相关新闻凑数。

## 7. 数据流与实现边界

1. `backfill-day --date 2026-08-05` 回补金十原始快讯与 Brent K 线，写入现有 SQLite。
2. 独立特朗普专栏抓取器按相同截止窗口抓取并缓存结构化 JSON，不混入 `raw_news` 正式归因池。
3. ISW 抓取器定位截止前最新文章，解析并完整翻译 Key Takeaways，写入独立缓存 JSON。
4. 现有报告生成器先构建价格异动、正式归因、蓝色面板和 Audit 数据。
5. 报告生成器加入特朗普板块和完整 ISW 板块，再从全部已验证内容生成顶部 2–5 条摘要。
6. Markdown 作为完整、可审计的文本产物；HTML 必须展示同一组摘要、特朗普表态和 ISW 条目，不得再做数量截断。
7. Audit 增加两个来源完整性区块：特朗普专栏抓取/过滤/合并说明，以及 ISW Key Takeaways 原文、翻译、渲染数量一致性。

## 8. 失败与降级处理

- 金十主快讯或 Brent 回补失败时，继续按现有状态机生成 `PARTIAL/FAILED` 产物，不伪造缺失数据。
- 特朗普专栏抓取失败时，正文保留板块并显示失败原因；不得回退到其他来源。
- ISW 官网解析不到 Key Takeaways、翻译不完整或数量不一致时，正文显示失败原因和原文入口；不得只展示成功翻译的前几条。
- 某一外部补充板块失败不改变主链路状态，但顶部摘要不得引用该失败板块。
- 所有时间必须带时区；显示使用北京时间，来源发布时间另可保留纽约时间。
- 外部缓存失败结果只有显式重试参数才重抓，避免无界重试。
